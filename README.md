**Що сьогодні, Мілорде?** — це хардкорна покрокова стратегія та симулятор управління ресурсами (Resource Management), що працює безпосередньо у терміналі. 

Гравець бере на себе роль лідера невеликого табору людей. Основна мета — вижити якомога більше днів в умовах постійної нестачі ресурсів, зміни пір року, хвороб та нападів розбійників.

## ⚙️ Основні механіки гри

Гра побудована на жорсткому математичному балансі та взаємозалежності змінних станів:

* **Динамічне населення та професії:** Поділ на дорослих (робітників) та дітей (споживачів 0.5 од. їжі). Дорослі призначаються на посади: *Фермери, Лісоруби, Каменярі, Будівельники*.
* **Система сезонів:** Кожен сезон триває 10 днів і безпосередньо впливає на `getFarmYield()`. Взимку ефективність фермерів падає втричі, і виникає обов'язкова потреба у спалюванні дерева (3 од. на кожну хатину) для уникнення смертей від холоду.
* **Жорсткий голод:** Дефіцит їжі автоматично конвертується у кількість смертей за формулою `ceil(abs(food))`. Смерті випадковим чином розподіляються між дорослими та дітьми з подальшим автоматичним звільненням з професій для уникнення від'ємних значень робочої сили.
* **Дипломатія та загрози:** Імплементовано систему "Загрози розбійників" (0-100%). Доступне меню торгівлі з сусіднім містом Альба (обмін ресурсів) та можливість сплати данини для зниження рівня загрози.

## 🛠️ Технічна архітектура (OOP)

Проєкт написаний на чистому C++ з використанням принципів об'єктно-орієнтованого програмування. Вся логіка інкапсульована у класі `VillageSimulator`.

* **Game Loop:** Стандартний цикл `while (!gameOver)`, який оновлює екран, чекає на консольний ввід користувача (`cin`) та викликає відповідні методи зміни стану або переходу на наступний день (`processDay()`).
* **Генерація випадковостей:** Замість застарілого `rand()` використовується `mt19937` (Вихор Мерсенна) та `uniform_int_distribution` для рівномірного та передбачуваного розподілу ймовірностей (народження, мандрівники, пожежі, напади вовків).
* **Рендеринг інтерфейсу:** Використовуються ANSI-escape послідовності (`\033[2J\033[1;1H`) для ефективного очищення терміналу та перемальовування UI поверх попереднього кадру без засмічення історії консолі.
